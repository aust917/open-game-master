# Элементы управления

Область: новые настройки, кнопки, поля, переключатели и их ревью.
Это сохранённые принципы upstream из первоначального `AGENTS.md`, вынесенные из стартового контекста.

1. Сначала выбери хороший default. Если он подходит большинству столов, отдельная настройка не нужна.
2. В создание кампании попадает только то, что нужно решить до первой сцены и чему нет безопасного default
   (сеттинг, ведущий истории, игроки, safety). Остальное меняется в настройках уже созданной кампании.
3. Одна идея — один control. Предпочитай preset picker; подробности открываются через Custom.
4. Показывай control только когда он применим: например, art style не нужен при выключенных изображениях.
5. Повторяющиеся предпочтения сохраняются в [личных defaults](../../src/app/create-campaign/defaults.ts).
6. До реализации запиши: что не работает без control, почему не помогает default/существующий control,
   кто им пользуется. Если обоснование есть, реализуй; отдельное подтверждение на каждую кнопку не требуется.
   В PR укажи обоснование и screenshot control с default в его реальном окружении.
7. Доступность: понятная видимая подпись, подсказка для неочевидных терминов; корректные label/aria/group/dialog;
   клавиатура и видимый focus; отсутствие действий только по hover; touch target ≥40px;
   читаемость на телефоне, в дневной и ночной темах; согласованность с соседними controls.
   Проверь web и оболочку приложения (`--app` в browser harness), axe для сценария `32-builder-a11y`.

Для русской локализации переиспользуй эти controls; не добавляй дублирующие переключатели языка.
