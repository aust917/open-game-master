# Серверные маршруты

- Доступ к кампании проверяется через `src/lib/campaign-api.ts`.
  `requireMember`, `requireVoice`, `requireLead` и права ведущего различаются:
  лидер стола с человеком-ведущим сам может быть игроком.
- `requireVoice` означает право публиковать реплики, а не наличие микрофона.
- Проверяйте тело запроса и принадлежность изменяемой сущности кампании
  на сервере; передавайте игровое действие существующим функциям движка.
- Поле, скрытое компонентом, остается утечкой, если попало в HTTP или SSE.
  Согласуйте ответы и события с `src/lib/dm/viewer.ts`,
  `src/lib/table-delivery.ts` и `src/lib/event-audience.ts`.
- В соседних маршрутах `params` — Promise; код, использующий SQLite,
  выполняется с Node.js runtime. Сохраняйте эти контракты при изменениях.
- Тесты маршрутов используют helpers в `scripts/lib/`; выбирайте существующий
  `scripts/test-*.mjs` по функции. Для прав доступа проверяйте разрешенный
  доступ, чужую кампанию и недостаточную роль.
