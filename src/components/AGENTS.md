# Общие компоненты

- Общие элементы интерфейса находятся в `ui/`; специфичные части стола —
  в `src/app/campaigns/[campaignId]/`. Расширяйте существующий элемент там,
  где уже находятся его состояние и события.
- Пользовательский русский текст не должен менять ID, enum, JSON-ключи
  или имена, по которым движок находит заклинание, предмет и состояние.
- Интерфейс отображает серверный результат действия. Не добавляйте клиентское
  списание игровых ресурсов или клиентскую защиту секретов вместо серверной.
- Для длинного русского текста проверяйте переносы, диалоги, клавиатуру,
  подписи для screen reader и ширину телефона. Общие правила новых настроек
  находятся в корневых инструкциях.
- Проверки, зависящие от effects, фокуса, потоковых событий или аудио,
  требуют браузера: static render не воспроизводит такое поведение.
  Сценарии — `scripts/browser/scenarios/`, запуск — `scripts/browser/run.mjs`.
